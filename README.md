# Blinkit-Sales-Analysis-PowerBI
Blinkit Sales Analysis using Power BI is a data analytics project that analyzes sales performance, customer trends, product categories, and outlet performance. The project uses Power BI to create an interactive dashboard and meaningful visualizations to derive business insights.
1. Project Objective:
Analyze Blinkit sales data using Power BI.
Identify sales trends and performance.
Understand product and outlet performance.
Generate useful business insights.

3. Tools & Technologies
Power BI – Dashboard and data visualization
Power Query – Data cleaning and transformation
DAX – Calculations and measures
Microsoft Excel – Data source and initial data preparation

4. Key Analysis:
Total Sales
Average Sales
Number of Items
Average Rating
Sales by Outlet
Sales by Item Category
Sales by Outlet Type
Sales trends and customer-related insights

5. Dashboard
Mention that the project includes an interactive Power BI dashboard with charts, KPIs, filters, and visualizations.

6. Conclusion:
This project demonstrates how Power BI can be used to transform sales data into interactive visualizations and meaningful business insights for better decision-making
